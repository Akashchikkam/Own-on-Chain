## 📋 First-Time Setup

1. **Open:** http://localhost:8069
2. **Wait** for page to load (1-2 minutes)
3. **Create Database:**
   - Database name: `test_erp`
   - Email: `admin@test.com`
   - Password: `admin`
   - Language: English
   - Country: Your country
   - Click **"Create Database"**

---

## ✅ Check Status

**Is Odoo running?**
```bash
docker ps | grep odoo
```

**Check logs:**
```bash
docker logs odoo-test
```

**Restart if needed:**
```bash
docker restart odoo-test
```
